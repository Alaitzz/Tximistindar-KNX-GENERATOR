ETS6 · KNX · Direcciones de grupo

Entiende una instalación KNX leyendo su dirección de grupo

Cada pulsador, regulador de luz o termostato de una vivienda KNX habla el mismo idioma: telegramas enviados a direcciones M/G/X. Este manual te enseña a leer ese idioma y a programarlo tú mismo en ETS6, con el mismo criterio que usa un integrador profesional.

Pulsa el interruptor

Esperando pulsación…

Al pulsar, el dispositivo no enciende nada directamente: envía un telegrama a una dirección de grupo. Cualquier actuador suscrito a esa dirección reacciona.

Regla fundamental

El último número de M/G/X identifica el circuito. No se renumera, no se compacta y no se reutiliza. Es la memoria del proyecto.

Cómo se usa este manual

Sigue el árbol de la izquierda en orden: direcciones → tipos de dato → módulos → casos prácticos. Cada sección construye sobre la anterior, igual que un proyecto ETS6 real.

01 · Estructura de direcciones

La dirección de grupo es una frase con tres palabras

En ETS6, en formato de 3 niveles, una dirección de grupo se escribe Principal / Medio / Sub. Cada nivel acota el significado del siguiente.

Zona o subsistema de la vivienda
Familia de función (ON/OFF, regulación, estado…)
Circuito. Este número no cambia nunca para ese circuito
Dirección resultante 1/2/07

El número final es la identidad del circuito

Si el circuito 07 es «Luz Salón Techo», entonces cada función relacionada con ese circuito conserva el 07 aunque cambie el grupo medio:

1/1/07ON/OFF del circuito 07
1/2/07Función asociada al circuito 07 (p. ej. regulación)
1/3/07Otra función asociada al circuito 07 (p. ej. estado)

Por eso nunca se renumera un circuito ni se reutiliza un número liberado: rompería esta correspondencia en todos los grupos medios a la vez.

Rangos especiales del subgrupo

000–099Elementos individuales
100–149Funciones centrales / colectivas
150–179Lógicas / automatismos especiales
180–199Reserva del sistema

Las reservas no se eliminan ni se compactan aunque estén vacías: forman parte de la metodología del proyecto.

02 · Datapoint Types

El DPT define qué significa el valor del telegrama

Una dirección de grupo sin DPT es solo un número. El DPT le dice al bus si ese telegrama es un booleano, un porcentaje, una temperatura o un número de escena. No se inventa: si el objeto depende del fabricante, se marca como pendiente.

FunciónDPTTipo de valorCategoría

Fallos, objetos de válvula o estados propios de un dispositivo concreto dependen del perfil de fabricante y no se documentan aquí como estándar.

03 · Módulos funcionales

Cada tipo de circuito tiene un patrón fijo de objetos

Un módulo es la lista de funciones que necesita un circuito para operar, separada de qué dispositivo físico las va a materializar. Primero se decide la función; después se mapea al producto.

04 · Caso práctico

Programa un pulsador de 1 o 4 teclas

Un pulsador no «sabe» encender ni regular nada: en ETS6 le asignas, por parámetro, qué telegrama envía cada tecla en pulsación corta y en pulsación larga. Configura las teclas y comprueba qué direcciones de grupo necesitas enlazar.

05 · Caso práctico

Una escena no crea una dirección por cada aparato

Una escena es un número (DPT 18.001) enviado a una única dirección de grupo. Cada actuador que participa en la escena ya está enlazado a esa dirección y tiene almacenado, en su propio parámetro, el valor que debe adoptar cuando llega ese número.

06 · Caso práctico

Suelo radiante y climatización por zonas

UFH_ZONE (suelo radiante) y HVAC_ZONE (aire acondicionado) comparten estructura: habilitación, temperatura ambiente, consigna, modo y demanda. Lo que cambia entre fabricantes es el objeto de demanda/válvula y el de fallo, que nunca se documentan por adelantado.
